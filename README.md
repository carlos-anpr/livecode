# Proyecto de Aplicación en React con TypeScript

## Descripción del Proyecto

Este proyecto es una aplicación web desarrollada con React, TypeScript y Vite. La aplicación permite a los usuarios gestionar y visualizar diseños de comunidad, así como realizar diversas operaciones relacionadas con la edición y visualización de archivos.

## Tecnologías Utilizadas

- **React**: Biblioteca de JavaScript para construir interfaces de usuario.
- **TypeScript**: Lenguaje de programación que añade tipado estático a JavaScript.
- **Vite**: Herramienta de construcción rápida y eficiente para proyectos web modernos.
- **Tailwind CSS**: Framework de utilidades CSS para diseñar interfaces de usuario.
- **Monaco Editor**: Editor de código embebido.
- **Framer Motion**: Biblioteca para animaciones en React.
- **HTML2Canvas**: Biblioteca para capturar el contenido de una página web como una imagen.
- **Lucide React**: Iconos SVG para React.
- **React Split**: Componentes para dividir la interfaz de usuario en paneles resizables.

## Instalación

1. Clona el repositorio:

2. Navega al directorio del proyecto:

   ```bash
   cd tu-repositorio
   ```

3. Instala las dependencias:

   ```bash
   npm install
   ```

4. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```

## Uso

### Funcionalidad de los Botones

- **Botón de Guardar**: Guarda el diseño actual en el almacenamiento local.
- **Botón de Cargar**: Carga un diseño guardado desde el almacenamiento local.
- **Botón de Exportar**: Exporta el diseño actual como una imagen PNG.
- **Botón de Importar**: Importa un diseño desde una imagen PNG.

### Estructura del Proyecto

- **`src/`**: Contiene el código fuente de la aplicación.
  - **`components/`**: Componentes de React.
  - **`data/`**: Datos iniciales y configuraciones.
  - **`hooks/`**: Hooks personalizados.
  - **`styles/`**: Archivos de estilo.
  - **`types/`**: Tipos de TypeScript.
  - **`App.tsx`**: Componente principal de la aplicación.
  - **`main.tsx`**: Punto de entrada de la aplicación.
